# Digimon World 2 Alternative GamerBapak Custom Patcher

Download release `v1.0.1` from [Releases](../../releases/latest).

| Platform | File |
| --- | --- |
| Windows 10/11 64-bit | `DW2-Alternative-GamerBapak-Custom-Patcher-v1.0.1.exe` |
| macOS | `DW2-Alternative-GamerBapak-Custom-Patcher-v1.0.1-macos.zip` |

## Usage

1. Apply [Digimon World 2 Alternative v6](https://github.com/Grensuingo/DigimonWorld2Alternative/releases/tag/6.0) to your own legally obtained Digimon World 2 BIN/CUE first.
2. Open patcher, then select resulting **Alternative v6** `.bin`.
3. Choose output location. Patcher creates separate output file. Alternative v6 source file stays unchanged.
4. Select team options, then build.

## Compatibility

This patcher works **only** with Digimon World 2 Alternative v6. It was tested against Alternative v6. Vanilla Digimon World 2 and other Alternative versions are unsupported.

No game files, ROMs, BIOS, base images, or original mod assets are included.
