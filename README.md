## Usage

1. Supply your own legally obtained Digimon World 2 base `.bin` and matching `.cue`.
2. Open patcher, select base BIN.
3. Choose output location. Patcher creates separate output file. Original base stays unchanged.
4. Select team options, then build.

No game files, ROMs, BIOS, base images, or original mod assets are included.
